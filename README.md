# DAAT

A responsive, high-performance studio website crafted with Next.js, Sanity, Motion for React, and Resend. 

Designed to reflect the precision of the DAAT identity, this platform features seamless page transitions, interactive canvas elements, and a bespoke typography system. The interface is built to showcase rich portfolio galleries, fluid motion graphics, and a dynamic branded experience without sacrificing accessibility or speed.

## Live Site
Explore the studio at **[daat.tech](https://daat.tech)**

## Core Features
* **Fluid Motion & Micro-interactions:** Custom cursor-driven particle physics, responsive image refraction, and pure-CSS interactive illustrations.
* **Dynamic Portfolio:** A seamlessly looping image wall, responsive masonry campaign grids, and interactive project cards with parallax effects.
* **Modern Architecture:** Server-rendered React via Next.js for optimal performance, paired with a headless Sanity CMS for real-time content updates.
* **Automated Booking:** Integrated Google Calendar scheduling for seamless client consultations.
* **Tailored Branding:** Exact SVG geometry for the DAAT wordmark and directional marks, styled with a custom layered gradient palette.
